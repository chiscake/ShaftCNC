# ShaftCNC

Веб-генератор управляющих программ для двухосевой токарной обработки вала: описываете заготовку и секции детали, получаете G-код и эскиз контура.

В каталоге [`docs`](docs/) — краткое руководство к программно-аппаратному тренажёру токарной обработки с ЧПУ ([Sunspire](https://sunspire.site/ru/)): программный симулятор двухосевого токарного станка и промышленная система **GSK 980 TDi**. В руководстве — состав изделия, работа с симулятором и панелью оператора, наладка (привязка инструмента и заготовки, MPG), синхронизация с контроллером и основы программирования в ISO G-коде.

PDF: [`docs/Токарный_тренажер.pdf`](docs/Токарный_тренажер.pdf)
